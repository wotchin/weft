Weft Settings

Configure your LLM API connection and preferences

LANG Language
Sets the interface language and asks the AI to answer in the same language, whatever language the source page is in. The interface is currently translated into English and 简体中文; other choices keep the English interface but still change the AI's answers.
API LLM Provider
Pick a provider to prefill its endpoint and a default model. Bring your own key — it never leaves your machine except to this endpoint.
Model identifier. Editable — model names change often.
Prefilled from the provider. Only change for self-hosted or proxy endpoints.
GEN Generation Options
0 = deterministic, higher = more creative (0-2)
Auto-detect works for known models (GPT-4o, Claude, Gemini, Qwen-VL, etc). Use "Always enabled" if your model supports vision but isn't recognized. Models like DeepSeek-chat that don't support vision will receive image URLs as text instead.
RAG Smart Context Retrieval
When enabled, only the most relevant snippets are sent to the AI based on your query. When disabled, all snippets are sent. Useful when sessions contain many snippets to reduce token usage and improve answer quality.
Maximum estimated tokens to include from snippets when RAG is active. Sessions smaller than 15K tokens will always send everything regardless of this setting.
WEB Web Search (optional)
Powers Deep Search and online cross-checking. Queries go only to the provider you pick. Weft never scrapes Google or Bing — that breaks their terms and gets extensions rejected.
The instance must have the JSON output format enabled (search.formats in its settings.yml). Most public instances turn it off, so this usually means running your own.
